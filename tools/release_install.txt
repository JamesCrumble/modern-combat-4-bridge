Modern Combat 4 Bridge - установка
=============================

Modern Combat 4 (Gameloft, v1.1.5, только 32-бит) на 64-битном телефоне через qemu-user и проброс GLES на GPU.
Файлы игры в комплект не входят: нужны ваши APK версии 1.1.5 и кэш к ней.

1. Установить MC4-Bridge-<версия>.apk (приложение "Modern Combat 4", пакет com.jamescrumble.mc4).

2. Запустить приложение и разрешить доступ ко всем файлам (приложение предложит само). Оно создаст папку

   /sdcard/BridgeGames/com.jamescrumble.mc4/

   Положить в неё два файла как есть (по кабелю с компьютера или файловым менеджером).
   Подойдёт и старая папка /sdcard/Android/data/com.jamescrumble.mc4/files/ : читаются обе, а при выданном
   доступе всё из неё переносится в BridgeGames само. Без доступа приложение работает с папкой в Android/data.


       <оригинальный APK игры 1.1.5>.apk          (не устанавливать, просто файлом)
       <zip-архив с кэшем игры>.zip            (не распаковывать)

   Имена файлов не важны, важны расширения. Архив нужен именно zip; приложение распакует его само
   при первом запуске игры.

   Вместо архива можно положить в ту же папку уже распакованную папку com.gameloft.android.ANMP.GloftM4HM
   (внутри files/ лежат AOWGame и Engine). Если копировали её по adb, откройте папки приложению:
       adb shell "find /sdcard/BridgeGames/com.jamescrumble.mc4 -type d -exec chmod 2777 {} +"

3. Открыть приложение: сначала появятся настройки (разрешение, лимит кадров, звук, ядра),
   кнопка "Играть" запускает игру. Первый запуск дольше: распаковывается sysroot (~100 МБ).

Исходники - MC4-Bridge-<версия>-src.zip (сборка описана в README.md).
Контрольные суммы - SHA256SUMS.
