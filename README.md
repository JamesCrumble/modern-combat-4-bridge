# MC4 Bridge

Modern Combat 4: Zero Hour 1.2.3e (Gameloft, только 32-бит) на 64-битном Android-телефоне: игра исполняется в
qemu-user внутри APK, её вызовы OpenGL ES уходят на GPU телефона. Альфа: главное меню, 60 кадров/с на OnePlus 13s.

Файлы игры в комплект не входят. Состояние, устройство и список недоделанного — в [PROJECT_STATE.md](PROJECT_STATE.md).

```sh
tools/build_install.sh noinstall   # порт + port/MC4-Bridge-debug.apk
tools/push_data.sh                 # APK игры (Ultra) и два OBB на телефон, папки открыты приложению
tools/launch.sh install            # установить и запустить
tools/pull_log.sh                  # лог -> logs/phone.log
```

## Файлы игры

**Папка BridgeGames.** С доступом ко всем файлам она основная: из `Android/data/com.jamescrumble.mc4/files/` туда сами переезжают все файлы
(APK, кэш, настройки, лог). Читаются обе папки, без доступа всё работает с папкой в `Android/data`. Сохранения игра хранит внутри папки кэша. Как это устроено и как перенести в другой порт: [docs/STORAGE.md](docs/STORAGE.md).

## Деньги

В настройках перед игрой, раздел «Деньги» (значения хранятся в `settings.txt`):

| Настройка | Ключ | Что делает |
|---|---|---|
| Бесконечные деньги | `MC4_MONEY_INFINITE` | Кредиты показываются как 9 999 999, покупки ничего не списывают; настоящий баланс не трогается, при выключении возвращается он плюс заработанное |
| Задать кредиты | `MC4_MONEY_RESTORE` | Одноразово: когда игра загрузит профиль, кредиты становятся этой суммой, после чего значение стирается; при бесконечных деньгах не действует |

Подмена стоит на `PlayerProfileBase::GetTotalCredits` и `RemoveCredits`; в игре ещё не подтверждена.

Подробная установка: `tools/release_install.txt`.
